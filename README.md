# 🍬 Uncle Sweet's Candy Co.

The chunkiest candy store on the internet. A single-page tribute website dedicated to Uncle Sweet — a chunky legend who crystallized from a sugar vat and now sells candy handmade with his bare chunky hands.

## Features

- 🍭 Full candy menu with 8 chunky-approved products
- 🛒 Working cart with live total counter
- ⭐ Sweet reviews (including some deeply concerned customers)
- 🫧 Floating candy cursor & hero bubble animations
- 🖱️ Click anywhere to spawn candy
- ⌨️ Press **S** to make it rain candy
- 🎨 Uncle Sweet's face tiled across the background

## Run Locally

Just open `index.html` in your browser, or serve it:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Tech

Plain HTML, CSS, and JavaScript. No frameworks, no build step, just sugar and vibes.
